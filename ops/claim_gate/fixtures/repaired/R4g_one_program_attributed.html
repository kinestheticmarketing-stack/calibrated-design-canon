Counting on a bonus total

The Combo Bonus is worth reading up on before the work is scoped, because the application window is short.

Building Science Corporation publishes a table in which the Combo Bonus is combined with whatever else the job qualifies for.

Derived from LGM 95c93d1, found by the defect B repair of 2026-09-18. R4's attributed exception -- publisher named in the sentence plus a cite key resolved on the artifact -- was gated on the two classes that existed when it was written, ASSERTS and DENIES, and was never wired into the -1P classes added 2026-09-17 or the -SET classes added 2026-09-18. So one attributed sentence was licensed when it named two programmes and failed when it named one. This is the MUST-NOT-FIRE half: one programme, the same combination predicate beside it, and the publisher now credited by name, which is a third party's own published combination reported with attribution. That is licensed, and it must be licensed from the one-programme class exactly as it already was from the two-programme class, or the exception turns on a sentence's name count rather than on its attribution.
