# QUARTERLY CHECK
Purpose: find what changed OUTSIDE the sites since the last check.
A finished site checked between quarters must return zero
findings. A finding that is not an outside change means the
standing gate is wrong: fix the gate once, as its own job.
Cadence: the 10th of January, April, July and October. The first
run is due now (2026-10-10); none has run before.
Per site, one kickoff, run in that site's repo:
1. Rebate programs. Confirm each program the site names against
   that program's own published page: still open, same structure,
   same eligibility. Correct to source. Then set the site's
   verified-date and next-review constants. No dollar figure is
   ever added. Never energy.gov.
2. Code editions. Re-check each town against its own ordinance.
   Standing re-checks: Northglenn after 2026-10-11; Longmont's
   electrical code after 2026-11-03; Greeley; and Milliken,
   Johnstown, LaSalle and Ault, which are recorded unconfirmed.
3. Read every page once by rules NR1, NR2, NR4 and NR7 only.
4. Word count per page against the last sealed tree. A page more
   than 5% shorter is a finding.
5. Every outbound link returns 200 and still shows the cited title.
6. Certificate days remaining for each domain.
7. Search Console: the page list behind each "not indexed" reason.
   Where the site has a read-only service account, the check reads
   it. The Director exports only where none exists. The check
   rules each page.
The Final Report states the finding count and the previous
check's count.
